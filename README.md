# LifeOS — Personal Life & Study Planner (v1.3.0)

**LifeOS** — персональный автономный веб-планировщик для ученика 10 класса, который автоматически составляет сбалансированное расписание на каждый день, учитывает школьные уроки (включая 8-е уроки во вторник и четверг), домашние задания, полноценную подготовку ко всем трём предметам ЕГЭ, олимпиады, проекты («Миросборка»), спорт, намаз ясту (Актаныш, Татарстан), отдых без компьютера, время с родителями и ежедневный час игр на ПК.

---

## 🌟 Ключевые возможности

0. **Календарь тем ЕГЭ**: заранее встроенный тематический маршрут по профильной математике, информатике и русскому языку. По каждому предмету: новая тема, на следующий день закрепление, затем повторение. Без обязательных тестов и без внешнего ИИ-сервиса. Основа — кодификаторы ФИПИ; учебные видео пользователь подбирает самостоятельно.

0. **Персональный тренер ЕГЭ**:
   - Стартовая диагностика из 20 вопросов по профильной математике, информатике и русскому языку.
   - Отдельная проверка базовых навыков геометрии, стереометрии, статистики и вероятности.
   - Результаты и ежедневные отметки хранятся локально в браузере.
   - Недельная ротация предметов с повторением слабых тем.
   - Ежедневный мини-урок: объяснение, разобранный пример и контрольный вопрос.
   - Содержание ориентировано на опубликованные материалы ФИПИ ЕГЭ-2027; программу года сдачи потребуется уточнить позже.

1. **Интеллектуальное автопланирование (Auto-Scheduler & AIPlanner)**:
   - Автоматически перестраивает расписание дня при добавлении ДЗ, отмене уроков или изменении планов — **без необходимости подтверждения**.
   - **3 режима работы**:
     - **Обычный**: сбалансированное развитие (школа, ДЗ, ЕГЭ, олимпиады, спорт, отдых).
     - **Загруженный**: автоматическая активация при объеме ДЗ > 120 мин или контрольных. Приоритет обязательным предметам, необязательные активности сокращаются.
     - **Соревновательный**: автоматическая активация перед хакатоном (проект «Миросборка», 27 ноября 2026 г.) или олимпиадой.
   - **Строго защищённые блоки (никогда не урезаются и не удаляются)**:
     - 🛏️ Физиологический сон: **21:30 – 06:00** (8 часов 30 минут).
     - 🕌 Вечерний намаз ясту (Иша): астрономический расчёт для с. Актаныш, Татарстан (UTC+3) с возможностью ручной корректировки.
     - 🎮 Игры на ПК: **60 минут ежедневно** (запланированный блок, не награда).
     - 🏃 Спорт: **25 минут ежедневно**.
     - 👨‍👩‍👧 Ужин с родителями и семейное время: **30 минут ежедневно**.
     - 🌿 Отдых без ПК: **45 минут перед сном**.
   - **Журнал изменений и откат (Rollback)**: кнопка «↩️ Отменить последнее перепланирование» в один клик.

2. **Школьное расписание и 8-е уроки**:
   - 6-дневная школьная неделя (Понедельник — Суббота).
   - Во вторник и четверг дополнительная математика — обычный 40-минутный 8-й урок (13:55–14:35); дорога домой около 25 минут (примерно до 15:00), затем 40 минут на обед.
   - Автоматический сдвиг времени возвращения домой и обеда без образования наложений.
   - Возможность добавлять/удалять уроки, менять кабинеты, отмечать отмену уроков и контрольные.

3. **Модуль домашних заданий**:
   - Быстрое добавление с оценкой времени, сложности (1–3), приоритета (низкий, средний, высокий, критический) и обязательности.
   - Автоматический подсчёт суммарного времени нагрузки, просроченных задач и нагрузки на следующий день.
   - Фиксация **фактического времени выполнения** при завершении.
   - Автоматический перенос выполненных задач в архив.

4. **Подготовка к ЕГЭ (3 предмета)**:
   - **Профильная математика**: полный кодификатор — **Часть 1 (задания 1–12)** и **Часть 2 (задания 13–19: уравнения, стереометрия, неравенства, экономика, сложная планиметрия, параметры, теория чисел)**.
   - **Информатика (КЕГЭ)**: задания 1–27, программирование на Python, алгоритмы, динамика, теория игр, обработка строк.
   - **Русский язык**: орфография (9–15), пунктуация (16–21), грамматика (7–8), работа с текстом и сочинение (27).
   - Учёт решённых задач, точности (% верных), журнал ошибок и дат повторения. Никаких случайных фиктивных цифр!

5. **Олимпиады и проекты**:
   - Проект **«Миросборка»** (ближайшее событие — **Хакатон 27 ноября 2026 г.**). Чек-лист этапов и задач, фиксация часов разработки.
   - Олимпиадный трекер (ВсОШ по математике и информатике, учёт задач и этапов). Регулярные слоты подготовки в расписании.

6. **Уведомления на рабочем столе Windows (Service Worker + Web Notifications API)**:
   - Локальные системные уведомления через Service Worker, пока LifeOS открыт; полноценный Web Push после закрытия браузера требует отдельного сервера.
   - Предупреждение за 5–10 минут до начала события, в момент старта и за 5 минут до окончания.
   - Специальные уведомления о намазе ясту и времени отдыха.
   - Мягкий звуковой перелив (Web Audio API Synthesizer) без внешних mp3 файлов.
   - Кнопка тестового уведомления и защита от повторных уведомлений.

7. **Честная статистика и аналитика**:
   - Реальные метрики: выполненные ДЗ, выполнение плана недели, часы ЕГЭ, олимпиадные задачи, время проектов, среднее время ДЗ, просроченные задачи.
   - 4 динамических графика на HTML5 Canvas (выполнение по дням, распределение продуктивного времени, прогресс ЕГЭ, план vs факт ДЗ).
   - При отсутствии данных честно выводится: *«Пока недостаточно данных»*.

8. **Локальное хранение и безопасность**:
   - Все задачи, расписания и история хранятся в **IndexedDB**.
   - Настройки хранятся в **LocalStorage**.
   - Полный **экспорт в JSON** и **импорт из JSON**.
   - Возможность безопасного подключения внешнего ИИ через Cloudflare Worker / Backend API без раскрытия ключей в коде.
   - Полная поддержка **PWA (Progressive Web App)** и офлайн-режима через `sw.js`.

## 🚀 Запуск приложения

### Вариант 1. Локальный запуск (быстрый старт)
Для полноценной работы PWA и Service Worker рекомендуется открывать сайт через любой локальный веб-сервер:

**Через Python:**
```bash
python -m http.server 8080
```
Затем откройте в браузере: `http://localhost:8080`

**Через Node.js:**
```bash
npx serve .
```

### Вариант 2. Публикация на GitHub Pages
1. Создайте репозиторий на GitHub (например, `lifeos`).
2. Загрузите файлы проекта в ветку `main`.
3. В настройках репозитория (*Settings -> Pages*) выберите источник `Deploy from a branch` -> ветка `main` -> папка `/ (root)` и нажмите **Save**.
4. Сайт будет мгновенно доступен по адресу: `https://<ваш-логин>.github.io/<имя-репозитория>/`

## 🏫 Восстановление школьного расписания

В версии v1.2.1 расписание, перенесённое из скриншотов пользователя от 23 ноября 2026 года, автоматически восстанавливается при первом запуске или при обнаружении прежней пустой сетки v1.2. Уже внесённые пользователем уроки не перезаписываются. Импортированное расписание требует проверки; в субботнем снимке видны четыре урока.

## 🕌 Расчёт намаза Ясту (Иша) в Актаныше

- **Координаты**: Широта `55.725° N`, Долгота `54.080° E`.
- **Часовой пояс**: `Europe/Moscow` (UTC+3).
- **Метод по умолчанию**: ДУМ РТ (астрономический угол заката солнца 15°).
- Время рассчитывается математически по формуле уравнения времени и склонения солнца на каждый конкретный день года.
- В настройках также доступен **ручной ввод времени** (если необходимо установить фиксированное время по расписанию местной мечети).
- Блок защищён от наложений и смещений планировщиком.

## 🛡️ Безопасность данных и архитектура

- Все персональные записи хранятся **исключительно локально** в браузере (IndexedDB + LocalStorage).
- Нет внешних серверов сбора персональных данных или обязательной авторизации.
- **Политика нулевого хранения секретов**: API-ключи никогда не сохраняются в браузере (LocalStorage / IndexedDB). LifeOS работает автономно на локальном детерминированном алгоритме. Внешний ИИ подключается только по желанию через защищённый серверный прокси без передачи ключей на клиент.
- В разделе **«Настройки»** можно в один клик скачать файл резервной копии (`lifeos-backup-YYYY-MM-DD.json`) и восстановить его в любом другом браузере или на новом устройстве с валидацией схемы и пред-импортным снимком.
